University Portal (Demo Page)

i. Universal Selector (*)
Explanation: Selects all elements on the page.
Rule used: * { font-family: Arial, sans-serif; } (Applied to the whole page).
ii. Class Selector (.classname)
Explanation: Selects elements with a specific class attribute. Used for reusable styles.
Rule used: .student-card { border: 2px solid #2980b9; }

iii. ID Selector (#idname)
Explanation: Selects a single, unique element with a specific ID. Used for main page elements.
Rule used: #main-title { color: #c0392b; } (Applied to the main heading above).
iv. Descendant Selector (parent child)
Explanation: Selects an element only if it is inside another specific element.
Rule used: nav a { background-color: #2c3e50; } (Styles links only inside the nav bar below).
Home Courses Library
v. Pseudo-class Selector (:hover)
Explanation: Selects an element when a specific state occurs (like hovering the mouse).
Rule used: nav a:hover { background-color: #e67e22; }
(Action: Hover your mouse over the dark blue menu links above to see them turn orange).
vi. Attribute Selector ([type="text"])
Explanation: Selects elements based on a specific attribute or attribute value.
Rule used: input[type="text"] { border: 2px dashed #27ae60; }
