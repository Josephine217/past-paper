Hyperlink Analysis for a Bank Intranet

Analysis of Hyperlinks

1. Absolute Hyperlinks

Definition: An absolute link contains the complete URL, including the protocol (http/https) and the domain name. It points to a specific, fixed location on the internet.

When to use in a bank intranet: Use absolute links when directing users to external websites outside the bank's internal network. For example, linking to the Central Bank of Kenya's website for regulatory guidelines, or a third-party pension provider's portal.

2. Relative Hyperlinks

Definition: A relative link points to a file or page relative to the location of the current document. It does not include the domain name (e.g., just `hr/leave.html`).

When to use in a bank intranet: Use relative links for internal navigation within the intranet itself. For example, linking from the main staff dashboard to the internal HR leave application form, or the monthly payroll page.
