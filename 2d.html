2(d) Importance of the 'alt' Attribute

Evaluation of Importance

The alt (alternative text) attribute provides a textual description of an image. It is a crucial accessibility feature, ensuring that web content is usable by everyone, regardless of their abilities or the device they use. For a public health website, where critical information must be universally understood, the alt attribute is vital.

Four Consequences of Missing Alt Text (For Different User Categories)

  • 1. Visually Impaired Users (Accessibility): Screen readers rely entirely on alt text to describe images. Without it, a blind user will just hear the word "image" or the file name (e.g., "covid_flyer_01.jpg"), completely missing the health information or instructions contained in the image.
  • 2. Users on Slow or Unstable Internet Connections: In regions with poor connectivity, images often fail to load. Without alt text, users see an empty box or a broken link icon. With alt text, they can still read the description (e.g., "Poster showing how to wash hands properly") and understand the message.
  • 3. Search Engine Users (SEO): Search engines like Google cannot "see" images; they read the alt text to understand what the image is about. If 80% of the images lack alt text, the website's search ranking will drop, making it harder for citizens to find vital health information online.
  • 4. Users with Blocked Images: Many corporate networks, email clients, or low-data browser settings block images by default to save bandwidth. Users in these categories will only see the alt text. If it's missing, the health graphic is completely lost to them.
